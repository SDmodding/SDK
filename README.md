## Usage
1. Clone repository
2. Use external include or mklink to the folder of SDK
3. Include main header file for SDK <kbd>**sdhd_sdk.hh**</kbd>
4. That's all, now you just going to need to study the whole SDK.

## Examples

If you're not sure where to start, check out the **[SDK Playground](https://github.com/SDmodding/SDK-Playground)**.

It contains small, focused examples demonstrating different parts of the SDK, with each project showcasing a specific feature or use case.
